# OGPlayer

**One video player SDK, three native implementations** — Android (Media3 + Jetpack Compose), iOS (AVFoundation + SwiftUI) and the web (hls.js + `<og-player>` custom element) — behind a single mirrored API.

HLS · live & DVR · multi-DRM (Widevine / FairPlay / PlayReady) · Google IMA & FreeWheel ads · subtitles & multi-audio · trick-play thumbnails · Chromecast & AirPlay · content ratings · fully themeable UI · stable cross-platform error codes.

**Free to evaluate** (watermarked, full feature set, no sign-up) · commercial license for production.
